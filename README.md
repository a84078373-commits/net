# STC SmartCare AI — حائل

تطبيق Flutter عربي يضم البلاغات المحلية والمساعد الإرشادي وخريطة جودة الإنترنت وخدمة قياس مستقلة.

## التشغيل المحلي

```sh
python -m pip install -r backend/requirements.txt
python -m uvicorn backend.app:app --host 127.0.0.1 --port 8765 --workers 1 --no-access-log
flutter pub get
flutter run -d chrome
```

عنوان API الافتراضي `http://localhost:8765`. للموقع المنشور أو الأجهزة، ابن مع `--dart-define=SMARTCARE_API_URL=https://your-domain.example`.

## وحدة جودة الإنترنت

- API فعلي، حسابات بكلمات مرور، جلسات، SQLite، تحقق من البيانات، وتجميع مكاني على الخادم.
- الخريطة الجغرافية من OpenStreetMap، والطبقة من خلايا قاعدة البيانات فقط. لا تُولد نقاط أو سرعات أو جودة عشوائية.
- فلاتر الزمن والاتصال والمؤشر والحدود والسرعة والاستجابة والعينات، ومقارنة الخلايا والتحديث اليدوي وبعد تحريك الخريطة.
- إذن الموقع ومشاركة الخلية اختياريان. لا تُرسل إحداثيات GPS دقيقة ولا تُنشر هويات القياسات الفردية.
- سجل القياسات الفعلية من حساب المستخدم، وحذفها من الخادم.
- لا يوجد خادم قياس إنترنت عام مُعدّ حاليًا؛ تظهر «اختبار الإنترنت غير متاح». قياس localhost لا يصنف على أنه إنترنت.

التوثيق الكامل: [backend/README.md](backend/README.md)، ويشمل القياس والخصوصية والإحصاءات والنشر وشروط القبول المتبقية.

## بقية التطبيق

البلاغات وتفاصيلها وحالتها، الملف المحلي والإعدادات والإشعارات داخل التطبيق، والمساعد الإرشادي بقواعد محلية، محفوظة محليًا. لم يُربط إرسال البلاغات إلى STC أو AI خارجي أو صلاحيات إدارة إنتاجية. لوحة البلاغات تعرض بيانات الجهاز فقط.

الحساب الجديد يتصل بالخادم فعلًا بكلمة مرور (12 حرفًا فأكثر)؛ لا يوجد رمز ثابت 123456. رقم الجوال معرّف غير متحقق برسائل SMS. جلسة الدخول في الذاكرة فقط. هذا المشروع ليس تطبيق STC رسميًا.

## التحقق

```sh
python -m pytest backend/test_api.py -q
flutter analyze
flutter test
flutter build web
```

بيانات الاختبارات في قواعد مؤقتة وMock فقط؛ لا توجد بيانات اصطناعية في قاعدة التشغيل. لم تُنفذ تجربة WAN على خادم عام أو اختبارات أجهزة فعلية بعد. لا تعتبر الواجهات أو الاختبارات المحلية اعتماد إطلاق 100%.
